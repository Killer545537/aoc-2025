# 🎄 Advent of Code 2025 🎄

Welcome to my Advent of Code 2025 repository!
Here you'll find my solutions implemented in Rust — fast, safe, and festive! ✨

## 📅 About Advent of Code

Advent of Code is an annual event where programming enthusiasts solve daily coding challenges throughout December. Each day brings a new puzzle, testing problem-solving skills and creativity.

## 🔧 Tech Stack

- Rust 🦀
- Anyhow for error handling
- Thiserror for custom error types
That's it! Keeping it simple and efficient.
